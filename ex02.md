# Problema 2: O Perfil de Jogador (Propriedades Calculadas e Formatação)
🎮 O Cenário:
Você está desenvolvendo um jogo e precisa de uma classe Jogador que guarde o nome e a pontuação. No entanto, os administradores do jogo exigem duas regras:

O nome do jogador nunca pode ser salvo com espaços em branco sobrando nas pontas (precisa dar um strip()).

Se o nome for alterado para uma string vazia, o sistema deve recusar.

💡 Como o @property e o @setter resolvem:
O @setter limpa e valida o nome automaticamente nos bastidores, e o usuário da classe nem percebe que existe uma lógica complexa rodando por trás de uma simples atribuição (jogador.nome = "  Maria  ").
